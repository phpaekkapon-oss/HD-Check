# SMART-HOSCHECK Frontend Dashboard

ระบบหน้าบ้าน React 19 + TypeScript (Strict Type-Safe) + Tailwind CSS v4 + Vite สำหรับงานตรวจสอบเวชระเบียนยาสมุนไพร

## การติดตั้งและรัน
```bash
cd frontend
npm install
npm run dev        # รัน Development Server (Port 5174 พร้อม Proxy ไปยัง Backend :3002)
npm run build      # Build Production Bundle (ลง dist/)
npm run preview    # พรีวิว Production Build
```
